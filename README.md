# skebob

Учебный проект: консольный помощник на Python, который шаг за шагом превращается в ИИ-агента с инструментами.

## Идея

```
  Вы (терминал)
       │  ввод текста
       ▼
┌──────────────┐     ┌────────────────────┐
│   main.py    │────▶│  Агент (мозг)      │──▶ Claude API (этап 4)
│  цикл ввода  │     │  решает, что делать│
└──────────────┘     └─────────┬──────────┘
                               │ вызывает инструмент
             ┌─────────────────┼─────────────────┐
             ▼                 ▼                 ▼
      ┌────────────┐   ┌────────────┐   ┌────────────┐
      │ calculator │   │   notes    │   │ read_file  │
      └────────────┘   └─────┬──────┘   └────────────┘
                             ▼
                       notes.json (хранилище)
```

## План по этапам

| Этап | Что делаем | Чему учимся |
|---|---|---|
| 1 | `main.py` с циклом: ввёл текст → получил эхо | переменные, циклы, ввод-вывод |
| 2 | Команды `add` / `list` / `done` для заметок в JSON | функции, файлы, словари |
| 3 | Разбить на модули, добавить тесты | структура проекта, pytest, git |
| 4 | Подключить Claude API — модель сама выбирает инструмент | агенты, tool use, API-ключи |
| 5 | Агент делает несколько шагов подряд | агентный цикл |

Каждый этап — отдельная ветка и pull request с ревью.

## Как запустить

```bash
python3 main.py
```

## Как запустить тесты

```bash
pip3 install pytest
python3 -m pytest
```
